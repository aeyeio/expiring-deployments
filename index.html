Expiring Deployments

Lightweight cleanup CronJob that watches annotated namespaces and Helm lease markers, then deletes or uninstalls them after TTL expiration. Designed for safety: dry-run default, protected namespace allowlist, and detailed run logs.

  • Namespace TTL: annotation-based expirations for preview/sandbox namespaces.
  • Helm TTL: release-scoped ConfigMap leases drive uninstall hooks.
  • Configurable selectors, circuit breaker, and optional owner validation.

Add the repo: helm repo add expiring-deployments https://aeyeio.github.io/expiring-deployments

Developer notes

Render or repackage with Nx:

npx nx run expiring-deployments:helm

Publish a new release via cr upload to update this repo + GitHub Releases.
